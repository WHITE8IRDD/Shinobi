## SHINOBI 1.7 — Playback & feed polish

Version code 11; Android 8.0 or newer.

- Fullscreen controls respect safe areas, with a 48 dp seek target, accessible seeking,
  elapsed/total time, and timestamp storyboard previews where YouTube supplies them.
  Controls stay visible while scrubbing. Fit preserves aspect; Fill crops without stretching.
- Rotation follows system auto-rotate while the player is open; manual fullscreen remains
  available with rotation lock on. The orientation listener stops when not needed.
- Shorts commits playback after a swipe settles, covers stale frames until the first new
  frame, and uses one service player with a three-second next-item preload. Comments load
  on demand. Extraction caches and queued prefetches are bounded.
- Shorts mixes rotating interests, likes, watch-next recommendations and discovery queries,
  with duplicate/dislike exclusion and creator caps. Short horizontal videos are no longer
  classified as Shorts just because of their duration. This is not YouTube's private algorithm.
- Landscape and portrait share player options: quality, speed, captions, autoplay, loop,
  queue, background/audio-only playback, playback stats, chapter navigation and an external
  YouTube reporting link. Existing mini-player and PiP are retained.
- SponsorBlock retains coloured segments, configurable categories, automatic sponsor skip
  and Undo, with corrected API parameters, defensive parsing and no paused polling.
- Optional **Sensitive thumbnail filter (experimental)** runs on-device, defaults off,
  and offers **Show anyway**. It conservatively detects explicit imagery, not every kind of
  suggestive content. False positives and missed content remain possible; it is not parental
  control and does not scan video frames. Home video previews stop while filtering.

### Verification and limits

The publishing workflow requires a successful build/test run for the exact APK source.
Regression coverage includes JVM parser/geometry/mixing tests, 17 emulator tests, fullscreen
seeking, actual local-video decoding across rotation, Shorts looping/next-item preloading,
model loading, and existing navigation/layout checks. Live YouTube availability remains
network-dependent. Offline emulator frame metrics are recorded with the test artifacts;
this is not certification of zero lag on physical phones or all networks.

Classifier provenance, licences, API research and limitations: `docs/research/polish-1.7.md`.

### Installation

Use **Shinobi-1.7-release.apk**. The repository still uses Android's debug signing configuration
for its minified sideload APK. An in-place update requires the same signing certificate as
an installed version; that continuity is not guaranteed by this repository's current CI.
Uninstalling a differently signed version removes its local data. The debug APK is included
for troubleshooting.
