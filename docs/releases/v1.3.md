## What's new in SHINOBI 1.3

- **Balanced Home:** signed-in and signed-out Home now share a deterministic recommendation mixer. It combines YouTube discovery, distinct watch-history interests and liked-video recommendations instead of expanding the newest topic repeatedly. A single personal seed is capped; missing sources do not let one like fill the page. Watched/disliked videos and duplicates are excluded.
- **Viewing signals:** newly opened videos become history recommendation seeds after at least five seconds of actual playback, not merely a tap or seek. Older history from 1.2 remains usable. History, likes, searches and dislikes remain stored on-device; related-video requests still go to YouTube.
- **Shorts first:** the Shorts shelf appears above Home's videos. The existing mixed-Shorts setting controls additional inline Shorts below that shelf.
- **Smart search:** YouTube search suggestions appear as you type, after a 250 ms debounce, alongside matching local searches. Stale requests are cancelled, results are briefly cached, and tapping a suggestion submits it. Typed query fragments are sent to Google's YouTube suggestion service; a full search is saved locally only when submitted.
- **Bilingual layout:** Arabic channel names, English text, counts and dates are isolated into independent directional runs. Video titles use their content's direction without flipping the whole English interface.
- **Trending:** open **Home → Trending**, then choose a country at the top. It loads YouTube's public regional chart, remembers the country, and shows an honest unavailable/retry state if YouTube provides no chart. It does not relabel ordinary search results as trending.
- **Centered S logo:** the Home header's logo is centered against the full bar, independently of the buttons on either side.
- **Responsiveness:** off-main-thread ranking, cancellable feed/search requests, lazy-list reuse, bounded caches and feed sizes, duplicate/repeated-token pagination stops, and removal of eager duplicate search/stream work.

## Validation and limits

The release pipeline runs unit tests, branding/zero-ads guards, and both debug and minified release builds. Regression tests cover source budgets, topic-binge seed diversity, duplicate/exclusion rules, search debounce/caching/stale responses, Home cancellation/retry/pagination, bilingual metadata isolation and trending parsing.

This is Shinobi's local recommendation algorithm combined with public YouTube responses—not a reproduction of YouTube's private algorithm. Country availability, autocomplete and discovery depend on YouTube's endpoints. Physical-device frame timing, visual alignment at every font/display size, and live YouTube responses were **not verified in the build environment**; zero lag on every device/network is not guaranteed.

## Installation

Download **Shinobi-1.3-release.apk** for normal use. Requires Android 8.0 or later. Version name **1.3**, version code **7**.

This release retains the repository's existing debug-key signing configuration. Its signing certificate may differ from an installed 1.2 APK, in which case Android will reject an in-place update. Uninstalling the old copy removes local history, likes and preferences; preserve anything important before choosing to reinstall. A stable private release signing key is needed for guaranteed future in-place updates.
