## SHINOBI ENHANCED (1.6) — release notes

Version name **1.6**, version code **10**. Android 8.0 (API 26) or later.

Built by GitHub Actions from the tagged source: 61 JVM tests, the branding and zero-ads guards, both APK builds and the emulator suite (narrow-screen English/Arabic layout checks plus the app screenshot tests below) pass in the same run.

### What changed

- **Trending shows YouTube's real charts.** YouTube retired its single Trending page on 21 July 2025 (`FEtrending` answers HTTP 400 for every client, as the CI probes still show). What the YouTube app lists instead are its per-category charts, and Home → Trending now lists exactly those through NewPipeExtractor's kiosks: **Music** and **Movies & trailers** from YouTube Charts where YouTube publishes them, **Gaming** and **Podcasts** everywhere. The country is requested explicitly for every load, so the list matches what YouTube lists for that country.
- **The region is detected automatically** — SIM country, then network country, then the device locale, refined by a silent YouTube check when the phone can't say — and selected on its own. The country picker stays on top ("Auto · United States"); the chart chips sit under it and only offer the charts YouTube publishes for that country, with a one-line note where Charts isn't available. Topic pills and the Shorts mix no longer appear while Trending is open.
- **First launch is empty on purpose.** Home shows *Your feed starts with you — Search or watch a few videos to warm up your feed.* with Search and Trending buttons, and no videos. NewPipe, LibreTube, PipePipe and Tubular were checked for how they build a recommendation feed: none of them drives a home feed from history (NewPipe/Tubular/PipePipe have subscription feeds and kiosks; LibreTube has trends and subscriptions), so Shinobi mirrors their building blocks — YouTube's watch-next per diverse history seed, likes, recent searches and YouTube's own suggestions — and balances them round-robin with per-seed and per-channel caps, so no topic floods the feed.
- **Logo:** the ninja "S" artwork is untouched. It is now centred on its real bounding box rather than the SVG canvas, in the launcher icon (a medium 43.6 × 49.0 dp glyph inside the 72 dp visible mask, 14.2 dp side and 11.5 dp top/bottom margins, well inside the safe zone), the header tile, the notification icon and the splash. Preview: `branding/preview/launcher-icon.png`, `docs/screenshots/08-launcher-icon-masks.png`.
- **Bottom navigation:** the pill sizes its tabs from the available width — compact icon-only tabs, a wide active tab whose label is measured to fit (14 sp down to 8 sp) — so "Subscriptions" and "الاشتراكات" fit on 320 dp screens and at 130 % text, as the emulator tests now assert.
- **Previews on Home:** when the list settles with a video in view, a few silent seconds of it play inside the card and fade back to the thumbnail (12 s at most). Tapping still opens the video; scrolling, leaving Home, a playing video or the app going to the background stops the preview at once. One small separate player, a low rung (~360p) through the same generated-DASH route as the player. **Settings → Feed → Previews on Home:** Always (default) / Wi-Fi only / Off.
- **Swipe between tabs:** a horizontal swipe moves to the adjacent tab (mirrored in Arabic), with the page sliding in from the revealed side. Mostly vertical drags go to the list, horizontal shelves and chip rows keep their own scrolling, and the gesture is off while a video, channel or playlist page is open.
- **Faster video starts:** the player begins from a modest bandwidth guess so the first chunk is a small one and the first frame comes sooner, then climbs to HD within seconds; the queue head and the top related video are extracted in the background; previews share the player's stream cache, so a previewed card opens without the extraction wait.
- **Smart search** (YouTube-style autocomplete while typing) and **mixed Arabic/English metadata** (isolated directional runs) were verified as already implemented; no change was needed.
- **Performance:** thumbnails share the app's connection pool and stay cached on disk regardless of headers; the tab-swipe detector survives recompositions instead of restarting mid-gesture; previews never run while the list scrolls.

### Limits

The emulator run uses whatever YouTube serves to a GitHub-hosted runner at the time; charts differ by country and day. Heavy-use frame timing on every phone, real-account sessions and every network cannot be certified from CI.

### Installation / signing

Download **Shinobi-ENHANCED-release.apk** for normal use; the debug APK is for troubleshooting. The release APK is minified and still signed with this repository's **debug-key signing configuration**: an in-place upgrade works over a build signed with the same key; otherwise uninstall first (that removes local history, likes and settings).
